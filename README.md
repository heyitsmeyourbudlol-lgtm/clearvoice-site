# ClearVoice site

Public GitHub Pages marketing site for **ClearVoice** (local-first voice dictation).

Mirrored to **[clearvoice-site](https://github.com/heyitsmeyourbudlol-lgtm/clearvoice-site)** for Pages.

- Ads, affiliate links, donation CTAs, digital goodies, and email capture live **only** here — not in the Electron desktop app.
- Replace all `PLACEHOLDER` strings (Sponsors, Ko-fi, BMC, PayPal, AdSense, Gumroad / Lemon Squeezy / Stripe Payment Links, ESP form actions, affiliate tags) before going live with real accounts.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080 --directory .
```
