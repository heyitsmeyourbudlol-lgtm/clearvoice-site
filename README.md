# ClearVoice site

Public GitHub Pages marketing site for **ClearVoice** (local-first voice dictation).

- Ads, affiliate links, and donation CTAs live **only** here — not in the Electron desktop app.
- Replace all `PLACEHOLDER` strings (Sponsors, Ko-fi, BMC, PayPal, AdSense, affiliate tags) before going live with real accounts.

```bash
python3 -m http.server 8080 --directory .
```
